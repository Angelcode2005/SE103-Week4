What a pull request asks teammates to do:
A pull request asks teammates to review the changes made in a branch before they are merged into the main branch. It gives reviewers a chance to check the work and provide feedback.

Why branches and pull requests are used together:
Branches allow developers to work on changes separately from the main branch. Pull requests then provide a way to review those changes before merging them into the main project.
